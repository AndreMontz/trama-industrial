# TRAMA Sistemas Industriais

Site institucional fictício para uma empresa brasileira de tecnologia industrial 4.0. A TRAMA transforma sinais de máquinas em decisões para manutenção, produção, energia e qualidade.

## Destaques

- identidade visual autoral com linguagem editorial-industrial;
- layout responsivo para celular, tablet e desktop;
- demonstração interativa da plataforma TRAMA OS;
- soluções, setores, caso de campo e processo de implantação;
- simulador de impacto financeiro;
- formulário com validação e feedback demonstrativo;
- páginas de privacidade, termos de uso e erro 404;
- navegação acessível, redução de movimento e metadados básicos;
- publicação automática do diretório `dist` pelo GitHub Pages.

## Estrutura

O site é estático e não exige instalação ou etapa de build. Todo o conteúdo publicado está em `dist/`.

## Publicação

O workflow em `.github/workflows/pages.yml` envia o conteúdo de `dist/` para o GitHub Pages a cada atualização da branch `main`.

> Todos os nomes, contatos, empresas, casos e indicadores apresentados são fictícios e servem apenas para demonstração.
